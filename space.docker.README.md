# Capital Markets Agentic Capstone

A training application for testers learning to test RAG pipelines, tool-calling
agents and MCP multi-agent systems, built on Indian equity derivatives.

**Bring your own key.** Open **⚙ Model & key** and paste a free API key (Groq is
the quickest to get). The key is kept in your browser, sent with each request,
and never stored on this Space. Without a key the app runs on a deterministic
offline stub, which is enough for most of the labs.

**Ollama does not work here.** A hosted Space cannot reach your laptop's
localhost. To use Ollama, run the project on your own machine.

Source, the 350-test suite and the trainee handbook are in the repository.

*Every market figure is educational and is not investment advice.*
